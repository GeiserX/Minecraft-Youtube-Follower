# CLAUDE.md — Minecraft YouTube Follower

## Overview
Docker-based system for 24/7 automated streaming of a Minecraft server. A spectator bot follows players with a smart third-person camera, showcases builds when the server is empty, and streams to YouTube or Twitch with hardware-accelerated encoding.

## Tech Stack
- JavaScript/Node.js (Mineflayer bot)
- Python (streaming service)
- Docker / Docker Compose
- FFmpeg (Intel iGPU hardware encoding)
- Mumble (voice chat integration)

## Development
```bash
# Configure
cp .env.example .env
# Edit .env with server, streaming key, etc.

# Run
docker compose up -d
```

Requires: Minecraft Java Edition account, Azure subscription (MS auth), YouTube/Twitch streaming key.

## Architecture
- `bot/` — Mineflayer spectator bot (Node.js)
  - `spectator-bot.js` — main bot entry point
  - `bot-logic.js` — camera and following logic
  - `__tests__/` — Jest tests
- `streaming/` — streaming and capture service (Python)
  - `streaming-service.py` — FFmpeg streaming orchestration
  - `capture-viewer.js` — screen capture from headless Minecraft
  - `music/` — background music assets
  - `download-music.sh` — music downloader scripts
- `docs/` — documentation and images

## Key Rules
- Never hardcode streaming keys, bot credentials, or Azure secrets
- Docker image: `drumsergio/minecraft-spectator-bot` with semver tags
- Supports Intel iGPU hardware-accelerated encoding (never default to CPU)
